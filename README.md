# MoneyMind Public Website

Static site for TikTok Developer URL requirements.

Deploy this folder publicly, then use:
- Web/Desktop URL: deployed root URL
- Privacy Policy URL: deployed `/privacy.html`
- Terms of Service URL: deployed `/terms.html`

Do not submit the TikTok app for review yet. First make sure all three URLs are publicly accessible and configure/verify them in TikTok Developer Portal.

The legal pages are a starting draft and should be updated with the actual owner/business contact details before production use.
